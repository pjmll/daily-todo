# 每日待办

一个 Windows 桌面待办工具。用它安排每天要做的事、设置时间提醒，在日历上回看完成记录，还能解锁陪你做事的小动物。

## 下载和运行

打开 [最新版下载页](https://github.com/pjmll/daily-todo/releases/latest)，在 Assets 下下载 `DailyTodo.exe`，放到常用的文件夹里双击运行。

升级时，先退出正在运行的旧版。如果程序在系统托盘里，右键任务栏右下角的「每日待办」图标，选择「退出」。再用新的 `DailyTodo.exe` 替换旧文件。新版会继续读取原有的待办和收藏记录。

## 待办、提醒和日历

- **新增待办**　输入事项名称，选择「今天」「明天」或「自选日期」，按 Enter 添加。日期、重复规则和提醒时间也可以在添加后编辑。
- **设置重复**　可选「每天」「工作日」或「每周指定」。例如只想在周一和周四提醒自己浇花，选「每周指定」，勾选周一和周四，再设置提醒时间。添加时选的日期是重复事项的开始日期。
- **设置提醒**　在「提醒」框输入时间，例如 `09:30`。弹出提醒时，可以直接标记完成，也可以选择「10 分钟后提醒」。有待办提醒时，关闭窗口会收进系统托盘，程序会继续提醒。也可以在托盘菜单里开启「登录 Windows 后在托盘运行」。
- **查看进度**　在「今天」处理到期和逾期事项，在「计划」查看未来待办，在「重复事项」管理重复规则。「日历」按实际完成日期显示每日完成数量，点日期可查看明细。
- **窗口置顶**　点「窗口置顶」，待办窗口会显示在其他普通窗口上方。再点「取消置顶」即可恢复。

## 互动伙伴和 Nuko 动图

下载版内置原创长毛猫、团子兔和栗栗鹿。点击进度卡上的伙伴，它会做出动作。完成待办时，它也会庆祝。连续 3 天每天都完成至少 1 项待办，就会从剩余伙伴中随机解锁一位。点「伙伴小屋」可以查看和切换已解锁的伙伴。

程序支持读取本机的 Nuko GIF。已有动图包时，将 `local-nuko` 文件夹放在 `%LOCALAPPDATA%\DailyTodo` 下，然后完全退出并重新打开程序。手动配置时，可以把一张动图命名为 `almond.gif`，放进该文件夹作为初始 Nuko。放入 `siamese.gif` 或 `orange.gif` 可增加相应的解锁款式，`cheer.gif` 用于完成待办时的庆祝。GIF 的宽和高各须不超过 160 像素，帧数须在 2 到 120 之间。

成功读取动图包后，「伙伴小屋」只显示 Nuko，此前解锁过的对应款式仍可使用。

## 备份和迁移

按 `Win + R`，输入 `%LOCALAPPDATA%\DailyTodo`，回车即可打开数据文件夹。`tasks.json` 保存待办和完成记录，`cats.json` 保存伙伴收藏，`local-nuko` 和 `local-portraits` 分别存放本机动图和个人头像。

换电脑时，先退出程序，再把整个 `DailyTodo` 数据文件夹复制到新电脑的 `%LOCALAPPDATA%` 下。重新打开程序即可继续使用这些记录。

## 从源码构建

在装有 .NET Framework 4.8 的 Windows 上，用 PowerShell 打开源码目录并运行以下命令。

```powershell
.\build.ps1
```

构建完成后，双击该目录生成的 `DailyTodo.exe`。程序使用 C# 和 WPF。
